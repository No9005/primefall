# Symbols and statuses: the overview for the in-game glossary (#385)

Overview pages of the design canvas ("Symbols and statuses"), as pictures. They show what the game drew when the canvas page was made, with the new looks marked "(new)". The game is the truth: a few entries are older than the code (for example "Zone: third (gold)" belongs to the old progress rule, and the Score pill is the interim VP display; see #362 and `docs/design/vp-hud/`).

- `marks-and-statuses.png`: marks and statuses on Heroes (Shield, planned Block, Slow, Marked, Hidden, Ghost, Exhausted, Overdrive, the permanent buff badge, planned Wait and self-played chips, Crossfire) and the floating numbers.
- `board-zones-fog-hud.png`: board (natural, placed and destroyed Cover, the zone looks, the Scout Drone area) and HUD parts (score pill, Round and timer pill, Queue, Deck pile, Commentary, Resolution bar).
