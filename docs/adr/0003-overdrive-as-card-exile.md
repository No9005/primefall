# Overdrive as Card Exile

Overdrive is an alternative mode on selected cards, not a separate card type. Activating Overdrive exiles the card and replaces or enhances its normal effect with a stronger effect; some Overdrives grant a permanent buff that disappears when the Hero becomes exhausted.

Each Hero Deck contains three Overdrive modes. The cost is future card economy, so Overdrive expresses the core Primefall tension: immediate power versus long-term survival.
