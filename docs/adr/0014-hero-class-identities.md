# Hero Class Identities

Primefall has three Hero classes with distinct tactical jobs, weapon ranges, and deck weights. The slash in names such as “Bruiser / Vanguard” identifies two labels for the same class archetype, not a class plus a separate hero variant.

- **Bruiser / Vanguard:** Range 3. Controls the Prime Zone and close space through Rush, close-range pressure, Shield, and Cover destruction. Deck: 6 Attack / 6 Utility.
- **Controller / Tactician:** Range 2. Enables the Squad through allied Shield, Vision, deployed Cover, Slow, and Marked effects. Deck: 4 Attack / 8 Utility.
- **Assassin / Striker:** Range 5. Scouts from Hidden, marks targets, and punishes exposed enemies with long-range precision and burst damage. Deck: 8 Attack / 4 Utility.

Cards with the same name always have the same effect. The Assassin’s Ghost Shot is the squad’s only tool that can target a Ghost’s last known position.

Complementary roles create squad-level decisions: who holds space, who enables, and who gathers information.
