# MVP Card Set

The offline 3v3 prototype uses a fixed set of 36 cards: 12 cards for each Hero class. Every card can alternatively be used as Pitch 1, Move 2, or Block 2, and a card fulfills only one of these roles during a round.

Cards with the same name have identical effects and identical Overdrive modes. Activating Overdrive exiles the card.

The complete card list is maintained in `docs/specs/mvp-card-set.md`.

A small fixed set keeps the first prototype balanceable while exercising every core mechanic.
