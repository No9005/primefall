# MVP Card Set

The offline 3v3 prototype uses a fixed set of 36 cards: 12 cards for each Hero class. Every card can alternatively be used as Pitch 1 or Move 3, and a card fulfills only one of these roles during a round.

Cards with the same name have identical effects.

The complete card list is maintained in `packages/game-core/src/cards.ts`; the principle behind the decks is in `docs/design/principles.md`.

A small fixed set keeps the first prototype balanceable while exercising every core mechanic.
