# PixiJS Skills: Full Index

Detailed routing table for the PixiJS v8 skill collection.

## Foundations

- `pixijs-application` — Create and configure a PixiJS Application.
- `pixijs-core-concepts` — Renderer pipeline, render loop, and environments.
- `pixijs-create` — Project scaffolding and TypeScript setup.
- `pixijs-environments` — Web Workers, Node/SSR, and strict CSP.
- `pixijs-migration-v8` — Upgrade from PixiJS v7.
- `pixijs-scene-core-concepts` — Scene graph, transforms, render order, masking, layers.

## Scene objects

- `pixijs-scene-container` — Containers, transforms, zIndex, bounds, coordinates.
- `pixijs-scene-sprite` — Sprite, AnimatedSprite, NineSliceSprite, TilingSprite.
- `pixijs-scene-graphics` — Vector shapes, paths, fills, strokes, gradients.
- `pixijs-scene-text` — Text, BitmapText, HTMLText, text styles.
- `pixijs-scene-mesh` — Custom geometry and meshes.
- `pixijs-scene-particle-container` — High-performance particle rendering.
- `pixijs-scene-dom-container` — HTML overlays on the canvas.
- `pixijs-scene-gif` — Animated GIF playback.

## Utilities

- `pixijs-assets` — Textures, sprite sheets, fonts, JSON, bundles.
- `pixijs-color` — Colors, tints, and conversion.
- `pixijs-events` — Pointer, mouse, touch, and wheel input.
- `pixijs-math` — Points, vectors, matrices, shapes, hit testing.
- `pixijs-ticker` — Frame updates and render-loop control.

## Advanced

- `pixijs-accessibility` — Screen reader and keyboard accessibility.
- `pixijs-blend-modes` — Standard and advanced compositing.
- `pixijs-custom-rendering` — Custom shaders, uniforms, and render pipes.
- `pixijs-filters` — Visual effects and filters.
- `pixijs-performance` — FPS, draw calls, and GPU memory optimization.
